# Acilin Enleri

Kurulum gerektirmeyen statik Firebase uygulaması.

1. GitHub deposundaki eski dosyaların tamamını silin.
2. Bu klasördeki `index.html`, `app.js`, `styles.css`, `firestore.rules`, `vercel.json` ve `README.md` dosyalarını köke yükleyin.
3. Firebase Firestore Rules ekranında `firestore.rules` içeriğini yayınlayın.
4. Vercel yeni commit'i otomatik yayınlar. Framework Preset `Other` olabilir; bu normaldir.
